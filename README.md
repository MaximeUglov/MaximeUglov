### <p align="center">Привет, меня зовут Максим, я ML-инженер. 👋</p>

<img align="right" src="https://i.giphy.com/media/v1.Y2lkPTc5MGI3NjExM2FiZTM5dDAwaG4wOWJnMHFhcm41YnU1ZGZpdXI3N2RxdnhqOHVhdyZlcD12MV9pbnRlcm5hbF9naWZfYnlfaWQmY3Q9Zw/AhjXalGPAfJg4/giphy.gif" width="400"/>

Я — ML‑инженер. Для меня важно, чтобы результат работы модели был не просто метрикой, а понятным бизнес‑эффектом: например, сразу оценить, сколько продаж нужно компенсировать скидкой и во сколько раз должен вырасти объём. Это помогает сразу видеть реальную пользу решения.   
    
Закончил курс по машинному обучению в karpov.courses, где разработал рекомендательную систему для социальной сети. После завершения курса меня пригласили работать экспертом на этом курсе. Теперь помогаю студентам с архитектурой и отладкой решений, провожу более 30 консультаций в неделю. Рейтинг моих консультаций — 4.8/5 по отзывам студентов.
